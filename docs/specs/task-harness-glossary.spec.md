# 任務合約用語

**任務合約**：同一任務的唯一權威約定與可恢復狀態，包含識別、範圍、完成條件、進度與恢復資訊。避免另稱任務參照來代表第二份內容。

**主責 agent**：對任務推進、驗收與合約維護負責的唯一協調者；委派不轉移其整體責任。

**必要成果**：有效約定中完成任務不可缺少的交付與驗證；不能自行改成後續建議。

**使用者工作回合**：由使用者要求啟動的一段授權工作；hook 的補救續作仍屬同一段，不產生新授權或額度。

**有界收尾補救**：正常收尾時對已啟用任務的一次核對與續作要求，不是完成保證，也不抵抗使用者停止。

**技術收據**：可歸屬到一次操作的觀測紀錄；不代替任務合約，也不證明任務成果正確。
