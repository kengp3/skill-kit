# H05C：中斷恢復與未知結果核對

**What to build:** 真實 agent 在原生中斷後保留有效成果，由新 session 明確接手同一任務合約；操作結果不明時查證實際產物而不重播副作用。

**Blocked by:** H05A（真實接入與控制合格）；不依賴 H05B 的產品結果。

**Status:** done（V4 通過；V3 經明確授權補驗後通過）

規格：[任務合約與必要 hooks](../specs/task-harness-lifecycle.spec.md)。案例及上限：[H05](task-harness-lifecycle-05-desktop.plan.md)。

- [x] 固定 V3／V4 的可丟棄材料、首次工作與明確續作輸入、interrupt 觸發、必要 session／turn 上限與直接判準。
- [x] V3 使用實際原生中斷，不以 stop 合約或合成事件冒充；核對終態及自有 writer 停止，再開新 session。
- [x] 中斷本身不授權續作；控制端只發預先授權的續作要求。新主責核對原合約、現況、有效成果及最新限制，成功保存接手後才推進。
- [x] 全程只有一份權威合約；只重驗受影響成果並完成最後整合驗證。最後一次未確認保存不被假定成功。
- [x] V4 使用一次可辨識的測試 append 產物與未知回應預置；agent 先讀回，再保存判斷，append 次數不增加。
- [x] 結果不明與停止未確認時不得重跑／接手；到期沿用原期限與既有控制，不另建監控或要求人工觀察。
- [x] 保存中斷、終態、writer、接手順序、合約／產物前後證據；預置故障與真實中斷明確區分。

完成條件：V3、V4 各項直接證據皆成立。第一次自然完成導致未觸發中斷，不算中斷驗收成功，也不擅自重跑整次案例。H05 最終結案另需 H05B 完成；此票不宣稱全套通過。

## 首輪結果與當時剩餘項（2026-10-25，歷史）

V4 先核對唯一 append，保存證據後才寫結果，ledger 未改、次數維持一；獨立 Spec 複核通過。V3 已保存部分合約，但固定控制端未觀測到 live-output 事件，前景命令自然結束；沒有發出 interrupt，也沒有開第二 session。修復產物 checker 3/3 不當成中斷／恢復通過。

只剩 V3：開發端已改為以已保存合約與指定命令的原生 started 事件觸發中斷，離線回放唯一命中且 7 個負例拒絕；原始 driver 保留，修正版未實際執行。只待依明確額度補驗一次，離線結果不替代取消與接手證據。原上限禁止整案補跑，本輪不追加。無須換模型、重跑其他案例、增加 OS/watchdog 或控制框架。見 [直接證據與限制](../research/h05-agent-behavior-validation.research.md)。

## V3 補驗完成（2026-10-25）

使用者明確允許一次 V3 補驗。兩個 sessions／兩次輸入，共用 900 秒期限，實際約 242 秒。原回合 interrupted，核對自有 writer 停止後才啟動第二段；新主責保存接手後完成未竟成果，唯一合約/task ID、T1 基線及固定輸入保留，維護者 checker 3/3。中斷命令沒有 final item 的限制明示，停止證據不依賴 ack。Standards／Spec 獨立複核均無發現。

本票必要成果已完成，不再有補驗待辦；原首輪未驗證紀錄不改寫。見 [最新驗收與限制](../research/h05-agent-behavior-validation.research.md)。
