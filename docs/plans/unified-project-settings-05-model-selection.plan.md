## 驗收條件

- [ ] 四預設階段及自訂階段，無固定全階段或模型要求。
- [ ] 支援分號模型清單與既定選擇優先序。
- [ ] 主責不自動切換；後續繼承跟隨最新對話選擇，既有 agent 維持原設定。
- [ ] 單次指定僅存合約，同任務恢復有效，新任務不沿用。

## 證據要求

F 正常派工的設定、來源、實際 agent／模型與任務範圍對照。

狀態更新只能依實際成果；調查、離線測試與真實行為驗收分別判定。
